## 💡 INSTRUCTIONS D'INSERTION

### Étape 1 : Créer les Enseignants
1. Aller dans "Gestion → Utilisateurs"
2. Créer 8 nouveaux utilisateurs avec le rôle "enseignant"
3. Remplir les informations personnelles
4. Compléter le profil enseignant (statut, heures contractuelles)

### Étape 2 : Créer les Classes
Assurez-vous d'avoir créé les classes suivantes :
- **2nde A** (Lycée)
- **1ère B** (Lycée)
- **6ème 1** (Collège)
- **3ème 2** (Collège)

### Étape 3 : Créer les Matières
Référez-vous au fichier `DONNEES_DEMO_MATIERES.md` ou créez les matières listées ci-dessus.

### Étape 4 : Assigner les Cours
1. Pour chaque cours listé, aller dans "Gestion → Cours"
2. Créer un nouveau cours
3. Sélectionner l'enseignant, la matière, la classe
4. Définir le volume horaire et la durée de séance
5. Choisir le type de cours (Cours Magistral, TP, TD, Atelier)
